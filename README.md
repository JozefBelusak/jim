# GymMate

Zaklad mobilnej aplikacie pre fitness komunitu postaveny na Expo, React Native a TypeScripte.

## Spustenie

```bash
npm install
npm start
```

Potom otvor Expo Go v telefone a naskenuj QR kod z terminalu.

## Overenie

```bash
npm run typecheck
```
